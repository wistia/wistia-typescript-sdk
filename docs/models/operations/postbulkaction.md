# PostBulkAction

A single action within a bulk request.

## Example Usage

```typescript
import { PostBulkAction } from "@wistia/wistia-api-client/models/operations";

let value: PostBulkAction = {
  operation: "delete",
  resourceType: "customization_chapters",
  id: "abc123",
};
```
