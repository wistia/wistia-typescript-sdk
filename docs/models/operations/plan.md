# Plan

The account's current plan information

## Example Usage

```typescript
import { Plan } from "@wistia/wistia-api-client/models/operations";

let value: Plan = {
  tier: "<value>",
  name: "<value>",
  isStandard: false,
  isTrial: false,
  trialExpiresAt: "<value>",
};
```
