# Users

Seat (user) usage and limits. Viewers are non-billable and excluded from the billable counts.

## Example Usage

```typescript
import { Users } from "@wistia/wistia-api-client/models/operations";

let value: Users = {
  billableCount: 260529,
  accountBillableCount: 918672,
  viewersCount: 893080,
  flexibleLimit: 619876,
  inflexibleLimit: 175337,
};
```
