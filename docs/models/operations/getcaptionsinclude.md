# GetCaptionsInclude

Set to `metadata` to omit caption text and return only track metadata.
Omitting this parameter preserves the existing response, including SRT text.


## Example Usage

```typescript
import { GetCaptionsInclude } from "@wistia/wistia-api-client/models/operations";

let value: GetCaptionsInclude = "metadata";
```
