# GetBrandsContrastIcons

Controls whether the player icon color is always white or uses an accessible contrast color when necessary.

## Example Usage

```typescript
import { GetBrandsContrastIcons } from "@wistia/wistia-api-client/models/operations";

let value: GetBrandsContrastIcons = "enabled";
```

## Values

```typescript
"enabled" | "disabled" | "unset"
```
