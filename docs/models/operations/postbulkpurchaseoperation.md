# PostBulkPurchaseOperation

Always `purchase`. This endpoint places orders only; to create, update,
or delete records in bulk use the Create Bulk Actions endpoint, which
does not accept `purchase`.


## Example Usage

```typescript
import { PostBulkPurchaseOperation } from "@wistia/wistia-api-client/models/operations";

let value: PostBulkPurchaseOperation = "purchase";
```
