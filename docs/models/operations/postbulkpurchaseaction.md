# PostBulkPurchaseAction

A single paid order within a bulk purchase request.

## Example Usage

```typescript
import { PostBulkPurchaseAction } from "@wistia/wistia-api-client/models/operations";

let value: PostBulkPurchaseAction = {
  operation: "purchase",
  resourceType: "text_translation",
  id: "abc123",
};
```
