# DownloadType

Which download quality is offered to viewers. Only takes effect when "download" is included in the channels array.

## Example Usage

```typescript
import { DownloadType } from "@wistia/wistia-api-client/models/operations";

let value: DownloadType = "sd_mp4";
```

## Values

```typescript
"sd_mp4" | "hd_mp4" | "original" | "all_qualities"
```
