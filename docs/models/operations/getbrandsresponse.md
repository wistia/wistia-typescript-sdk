# GetBrandsResponse

A brand is a saved set of branding options — colors, fonts, logos, and
layout — that can be applied to media, projects, channels, and webinars.


## Example Usage

```typescript
import { GetBrandsResponse } from "@wistia/wistia-api-client/models/operations";

let value: GetBrandsResponse = {
  name: "My Brand",
  isDefault: true,
  created: new Date("2010-08-13T18:47:39+00:00"),
  updated: new Date("2010-08-19T21:47:00+00:00"),
  primaryColor: null,
  pageBackgroundColor: "#111111",
  bodyFontFamily: "Inter",
  headlineFontFamily: "GT Walsheim",
  buttonFontFamily: "Inter",
  borderRadius: 10,
};
```
