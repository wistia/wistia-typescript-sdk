# GetBrandsBrandIdResponse

layout — that can be applied to media, folders, and channels.

  created: new Date("2010-08-13T18:47:39+00:00"),

  primaryColor: "#2949E5",
  pageBackgroundColor: null,
  bodyFontFamily: "Inter",
  headlineFontFamily: "GT Walsheim",
  buttonFontFamily: "Inter",
  borderRadius: 10,
};
