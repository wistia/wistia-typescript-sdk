# GetShareLinksIdentifierResponse

A shareable link for a single media. Each media can have at most one
share link, and the link's `visibility` controls who can view the
media when visiting the link.


## Example Usage

```typescript
import { GetShareLinksIdentifierResponse } from "@wistia/wistia-api-client/models/operations";

let value: GetShareLinksIdentifierResponse = {
  id: "<id>",
  mediaId: "<id>",
  url: "https://crafty-hoof.biz",
  slug: "<value>",
  visibility: "domain_verified",
  createdAt: new Date("2025-06-28T02:21:14.019Z"),
  updatedAt: new Date("2024-08-05T05:22:33.646Z"),
};
```
