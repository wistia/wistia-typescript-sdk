# PostBulkPurchaseRequest

A bulk purchase request, in one of two shapes.

Send `actions` to name each media individually, and `job` to order for every
media under a parent. Provide exactly one of them -- a request carrying both
is rejected, and so is a request carrying neither.


## Example Usage

```typescript
import { PostBulkPurchaseRequest } from "@wistia/wistia-api-client/models/operations";

let value: PostBulkPurchaseRequest = {
  actions: [
    {
      operation: "purchase",
      resourceType: "extended_audio_description",
      id: "abc123",
    },
  ],
  job: {
    operation: "purchase",
    resourceType: "captions",
    scope: {
      type: "account",
      id: "abc123",
    },
    ids: [
      "abc1234567",
      "def8901234",
    ],
  },
};
```
