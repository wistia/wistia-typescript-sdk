# PutMediasMediaIdShareLinkResponse

A shareable link for a single media. Each media can have at most one
share link, and the link's `visibility` controls who can view the
media when visiting the link.


## Example Usage

```typescript
import { PutMediasMediaIdShareLinkResponse } from "@wistia/wistia-api-client/models/operations";

let value: PutMediasMediaIdShareLinkResponse = {
  id: "<id>",
  mediaId: "<id>",
  url: "https://dreary-range.info/",
  visibility: "locked",
  createdAt: new Date("2026-07-07T02:42:30.353Z"),
  updatedAt: new Date("2025-10-07T20:42:19.016Z"),
};
```
