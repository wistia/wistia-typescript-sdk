# PostBulkRequest

A bulk request, in one of two shapes.

Send `actions` when each record needs its own payload, and `job` when the
same change applies to every record under a parent. Provide exactly one of
them -- a request carrying both is rejected, and so is a request carrying
neither. To make a mixed change, send two requests.


## Example Usage

```typescript
import { PostBulkRequest } from "@wistia/wistia-api-client/models/operations";

let value: PostBulkRequest = {
  actions: [
    {
      operation: "update",
      resourceType: "customization_playback",
      id: "abc123",
    },
  ],
  job: {
    operation: "update",
    resourceType: "customization_thumbnail",
    scope: {
      type: "subfolder",
      id: "abc123",
    },
    ids: [
      "abc1234567",
      "def8901234",
    ],
  },
};
```
