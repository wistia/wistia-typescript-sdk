# UpdateBrandPreloadRequest

Payload for `PUT /brand_preload`. Both fields are optional independently;
omit either to leave that account setting untouched. Sending `null` for
either field is not accepted — use omission for "leave unchanged" and an
empty string for the documented clear operation on logo.


## Example Usage

```typescript
import { UpdateBrandPreloadRequest } from "@wistia/wistia-api-client/models/operations";

let value: UpdateBrandPreloadRequest = {};
```
