# PageBackgroundColor

The brand color used for page backgrounds. Either a hex color string or a gradient represented as an array of [hexColor, percentage] tuples. Null when unset.


## Supported Types

### `string`

```typescript
const value: string = "#111111";
```

### `any[][]`

```typescript
const value: any[][] = [
  [
    "<value 1>",
    "<value 2>",
    "<value 3>",
  ],
  [
    "<value 1>",
    "<value 2>",
    "<value 3>",
  ],
];
```
