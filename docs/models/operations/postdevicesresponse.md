# PostDevicesResponse

A registered push notification device token for the Wistia desktop app.
Used to deliver activity notifications (new comments and views)
for media created via the desktop app.


## Example Usage

```typescript
import { PostDevicesResponse } from "@wistia/wistia-api-client/models/operations";

let value: PostDevicesResponse = {
  deviceToken:
    "6a41c6f2e5b1d3f4a7c8e9b0d1f2a3c4e5b6d7f8a9c0b1d2e3f4a5b6c7d8e9f0",
  bundleId: "com.wistia.glass",
  environment: "sandbox",
  createdAt: new Date("2026-07-07T18:47:39+00:00"),
};
```
