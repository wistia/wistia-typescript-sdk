# GetMediasMediaHashedIdInclude

Set to `speakers` to include active transcript speaker assignments used for diarization. Webinar hosts and panelists are not included.

## Example Usage

```typescript
import { GetMediasMediaHashedIdInclude } from "@wistia/wistia-api-client/models/operations";

let value: GetMediasMediaHashedIdInclude = "speakers";
```
