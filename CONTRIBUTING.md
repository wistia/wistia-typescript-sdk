# Contributing to This Repository

Thank you for your interest in contributing to this repository. Please note that this repository contains generated code. As such, we do not accept direct changes or pull requests. Instead, we encourage you to follow the guidelines below to report issues and suggest improvements.

## How to Report Issues

If you encounter any bugs or have suggestions for improvements, please open an issue on GitHub. When reporting an issue, please provide as much detail as possible to help us reproduce the problem. This includes:

- A clear and descriptive title
- Steps to reproduce the issue
- Expected and actual behavior
- Any relevant logs, screenshots, or error messages
- Information about your environment (e.g., operating system, software versions)
    - For example can be collected using the `npx envinfo` command from your terminal if you have Node.js installed

## Issue Triage and Upstream Fixes

We will review and triage issues as quickly as possible. Our goal is to address bugs and incorporate improvements in the upstream source code. Fixes will be included in the next generation of the generated code.

## Regeneration Pull Requests (maintainers)

This SDK is regenerated by Speakeasy via the `Generate` workflow. Each run pushes
to an automation-owned branch (`speakeasy-sdk-regen-*`) and opens — or force-updates —
a single pull request against the target branch (`main` or a `vYYYY-MM` version branch).

**Never push commits to a `speakeasy-sdk-regen-*` branch.** The generation action
audits the branch before refreshing it; if it finds any non-automated commit it
refuses with `external changes detected` — and every future regeneration for that
target fails until the offending PR is merged or closed. The failure typically
surfaces weeks after the commit that caused it.

If a regen PR has failing tests or otherwise needs a manual fix:

1. Merge or close the regen PR as-is.
2. Land your fix on the target branch as its own PR.
3. Re-run the `Generate` workflow on that branch (or wait for the next OAS change)
   to get a fresh regen PR.

The bot's branch belongs to the bot.
